# Think Lab. ✦ Agencia de Ingeniería Web & IA

Sitio web oficial de **Think Lab.** — Agencia de desarrollo web de élite especializada en plataformas digitales sobrias, ultra-rápidas (Core Web Vitals 100/100) y automatizaciones avanzadas con agentes de Inteligencia Artificial.

---

## ⚡ Características Principales

- **Estética de Ultra-Lujo (Estilo Apple)**: Minimalismo puro en negro profundo (`#000000`), microinteracciones a 60 FPS y tipografía suiza.
- **Calculadora Interactiva de ROI**: Motor en tiempo real para proyectar incremento de facturación.
- **Artesanía de Diseño & Showcase**: Muestrario de sistemas de diseño y arquitectura modular.
- **El Blueprint de 5 Fases**: Cronograma interactivo del proceso de desarrollo en 4 semanas.
- **Cotizador & Auditoría**: Formulario interactivo en 3 pasos con validación en vivo.
- **Asistente ThinkBot AI**: Widget conversacional flotante integrado.
- **Botón Oficial de WhatsApp**: Enlace con logotipo oficial SVG a soporte comercial.

---

## 🛠️ Stack Tecnológico

- **Frontend**: HTML5 Semántico, Tailwind CSS (CDN), Vanilla JavaScript ES6+.
- **Iconografía**: Lucide Icons & SVG vectoriales oficiales.
- **Tipografía**: SF Pro / Plus Jakarta Sans & JetBrains Mono.
- **Despliegue Recomendado**: Vercel, Netlify o GitHub Pages.

---

## 🚀 Inicio Rápido Local

Para visualizar el proyecto localmente:

```bash
# Con Python 3
python3 -m http.server 8000
```

Abre en tu navegador: `http://localhost:8000`
