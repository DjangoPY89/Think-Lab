# ThinkLab (https://thinklabpy.online/)

Plataforma oficial de **ThinkLab**: Ingeniería Web de Alto Rendimiento, Aplicaciones Móviles y Chatbots & Agentes de IA Autónomos.

## 🚀 Tecnologías
- **Frontend**: HTML5, Tailwind CSS, JavaScript Vanilla, Lucide Icons, Canvas Particles.
- **Backend**: Node.js, Express.js.
- **Base de Datos**: SQLite Native (`thinklab.db`).
- **Capacidades**:
  - Simulador de Chatbots & Agentes de IA en tiempo real.
  - Calculadora de Retorno de Inversión (ROI).
  - Think Bot AI: Asesor conversacional experto con agendador de llamadas integrado y conexión directa a WhatsApp.
  - Panel de Administración en `/admin` para métricas, leads, citas y registros de chat.

## 📦 Instalación y Ejecución Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor
node server.js
```

El servidor iniciará en `http://localhost:8000`.
